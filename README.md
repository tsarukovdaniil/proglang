*Переведите в двоичную запись два произвольных рациональных числа (числа вида* $\frac{p}{q}$).

Дробная часть: 0.72 = 1.4 (1), 0.42 = 0.8 (0), 0.82 = 1.6 (1), 0.62 = 1.2 (1), 0.2*2 = 0.4 (0). Период 0110. Итого: 1110001.1(0110).
Нормализация: 1.1100011(0110) * 2**6. Порядок E = 6 + 1023 = 1029 = 10000000101.
Мантисса (52 бита): первые биты 1100011, затем период 0110 повторяется. 52 - 7 = 45 бит. 45 / 4 = 11 полных периодов (44 бита) + 1 бит (0). Следующие биты 1100... > 1000..., округление вверх. Последний 0 становится 1.
Ответ: 0 10000000101 1100011011001100110011001100110011001100110011001101.


### Задание 3 **(3)**
*Найдите сумму и произведение для записанных далее пар чисел. Числа заданы в двоичной записи 
в экспоненциальном виде. Ответ необходимо записать в нормализованннои экспоненциальном виде.*

* 1.0011e18 и $1.1001e21;
* 1.1011e-25 и, $1.1101e-23;
* 1.1011e-3 и $1.1011e1.
  
*При решении задачи нельзя 
использовать вычислительную технику. Процесс решения должен быть представлен в отчете.*

1. 1.0011 * 218 + 1.1001 * 221. Выравнивание: 0.0010011 * 221 ≈ 0.0010 * 221. Сумма: 1.1001 + 0.0010 = 1.1011. Ответ: 1.1011e21.
Произведение: 1.0011 * 1.1001 = 1.11011011. Порядок 18+21=39. Ответ: 1.1101e39.
2. 1.1011 * 2**(-25) + 1.1101 * 2**(-23). Выравнивание: 0.011011 * 2**(-23) ≈ 0.0110 * 2**(-23). Сумма: 1.1101 + 0.0110 = 10.0011 = 1.00011 * 21. Порядок -23+1=-22. Ответ: 1.0001e-22.
Произведение: 1.1011 * 1.1101 = 11.00001111 = 1.100001111 * 21. Порядок -25-23+1=-47. Ответ: 1.1000e-47.
3. 1.1011 * 2**(-3) + 1.1011 * 21. Выравнивание: 0.00011011 * 21 ≈ 0.0001 * 21. Сумма: 1.1011 + 0.0001 = 1.1100. Ответ: 1.1100e1.
Произведение: 1.1011 * 1.1011 = 10.11011001 = 1.011011001 * 21. Порядок -3+1+1=-1. Ответ: 1.0110e-1.

### Задание 4 **(2)**

*Рассмотрим следующий пример в IDLE Python*
```
>>> x = 99.99
>>> int(x/10+0.001)
9
```
*Результат должен был быть равен 10, однако оказался другим. Почему так произошло?
Как исправить программу, чтобы она корректно переводила вещественные числа в целые?*

Решение.Числа 99.99 и 0.001 нельзя записать в двоичной системе точно, в памяти лежат приближённые значения. Поэтому x/10 получается чуть меньше, функция int отбрасывает дробную часть, поэтому ответ 9.
Исправление: round(x/10 + 0.001) = 10.
