3. Как **a, (b = b), a**

### Задание 7 **(2)**

*Как работает следующая программа? Как зависит результат от исходного значения?*
```

x-->0 && x-->0 && x-->0 && x-->0 && x-->0;
std::cout << x;
```
**Ответ:** Программа делает пять проверок и после каждой проверки уменьшают x на 1. Если проверка выдаёт ложь x всё равно уменьшается. После всех проверок в зависимости от значения x:
    1. Если x >= 5, x = x - 5
    2. Если 1 <= x <= 4, x = -1
    3. Если x <= 0, x = x - 1
